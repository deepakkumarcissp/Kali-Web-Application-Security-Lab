# DKCISSP Guided Missions

These mission sheets add learning structure around the intentionally vulnerable Juice Shop application. Complete them only against the local lab at `http://127.0.0.1:1002`.

For each mission, record:
1. The security question you are investigating.
2. The request, response, or UI behaviour that supports your finding.
3. The likely root cause.
4. A recommended remediation.
5. How you would retest the fix in a real application.

The missions are learning guides, not proof that the application is secure. Exact challenge availability can vary by application version; if a described feature differs, record that difference rather than testing an unrelated system.
